資格 (情報セキュリティ)

目次

Macro (toc)

概要

情報セキュリティに関する資格情報をまとめていきます。資格の管理団体は教育法人、NPO、協会、ベンダーから構成されています。

一覧

種類 知識体系 管理団体 説明
NPO CISSP (Certified Information Systems Security Professional) ISC2 CISSPは、情報セキュリティ分野での専門知識とスキルを持つプロフェッショナル向けの国際的な資格です。CISSPは、情報セキュリティポリシー、リスク管理、セキュリティアーキテクチャ、アクセスコントロール、ソフトウェア開発セキュリティ、通信およびネットワークセキュリティ、セキュリティ操作、セキュリティ監査、セキュリティ法律と倫理など、さまざまな情報セキュリティ領域をカバーしています。
※ 参考 /space/knowledge/7962733/
協会 CySA+ (Cybersecurity Analyst) CompTIA CySA+は、サイバーセキュリティアナリスト向けのコンピュータセキュリティ資格であり、コンピュータネットワークのセキュリティインシデントの検出と対応に関するスキルを評価します。CySA+認定資格保有者は、セキュリティイベントの監視、分析、および対応の専門家として活動できることを示すものです。
ベンダー AWS SCS (AWS Certified Security - Specialty) AWS AWS SCSは、Amazon Web Services（AWS）クラウドプラットフォームにおけるセキュリティに関するスペシャリスト向けの認定資格です。この資格は、AWSのセキュリティ関連サービスやベストプラクティスについての知識を証明します。
ベンダー AWS ANS (AWS Certified Advanced Networking - Specialty) AWS AWS ANSは、AWSのネットワーキングサービスとアーキテクチャに関する高度な知識を持つプロフェッショナル向けの認定資格です。AWSクラウド内でネットワーキングソリューションを設計、実装、運用する能力を評価します。
ベンダー MCP SC-900 (Microsoft Certified: Security, Compliance, and Identity Fundamentals) Microsoft MCP SC-900は、Microsoftのセキュリティ、コンプライアンス、およびアイデンティティに関する基本的な知識を持つプロフェッショナル向けのマイクロソフト認定資格です。この資格は、セキュリティに関する基本的なコンセプトとテクノロジーに関する知識を証明します。
ベンダー GCP PCSE (Google Cloud Professional Cloud Security Engineer) Google GCP PCSEは、Google Cloudのセキュリティエンジニア向けの認定資格で、Google Cloudプラットフォーム上でのセキュリティソリューションの設計、実装、運用に関するスキルを評価します。持っていると、Google Cloudでのセキュリティ関連のプロジェクトでの能力を示すことができます。
