あなたのビジネスパートナー、BnG

Blahfe & Grpr (BnG) は、代表の猪瀬学 (nabinno) によって運営されるITコンサルティングおよびセキュリティサービスを提供する個人事業です。代表は、豊富なデータインフラストラクチャと情報セキュリティの知識を持ち、企業の情報システム戦略と組織マネージメントの専門家です。副業としてこのサービスを提供し、月に約15時間稼働しています。

# BnGについて

# **ビジョン**

テクノロジーを駆使して企業の独自の課題を解決し、ビジネスの成長を加速させます。技術進歩に注目し、その統合を目指します。

# **メンバー**

多くのIT業界経験を持ち、データインフラストラクチャ、情報セキュリティ、組織マネージメントの分野に深い知識を有しています。

# **ナレッジ**

セキュリティとプライバシー、ビジネス戦略とマネージメント、インフラとシステム開発など多角的なジャンルを扱っています。

# なぜBnGを選ぶのか

## 3つの専門領域を横断

技術（テクノロジー）、経営（ビジネス）、セキュリティの三位一体の知見で、複合的な課題に対応します。

## 柔軟な副業体制

月額固定費なしの従量課金制、スポットコンサルから定期支援まで対応、迅速なSlackレスポンスでいつでも相談可能です。

## 実績に裏打ちされた知識

データインフラストラクチャ設計・情報セキュリティ管理・組織マネージメントの豊富な実務経験を活かし、最適な解決策を提供します。
