# 概要

データ工学に関する資格情報をまとめていきます。資格の管理団体は教育法人、協会、ベンダーから構成されています。

# 一覧

| 種類 | 知識体系 | 管理団体 | 説明 |
| --- | --- | --- | --- |
| 教育法人 | DataCamp DEA (DataCamp Certified Data Engineer Associate) | DataCamp | データエンジニアリングに関する知識とスキルを持つプロフェッショナル向けの資格です。データエンジニアリングは、データの収集、処理、保存、および分析に関連するさまざまなテクニカルスキルをカバーしています。 |
| 教育法人 | DataCamp DAA (DataCamp Certified Data Analyst Associate) | DataCamp | データ分析に関する知識とスキルを持つプロフェッショナル向けの資格です。データ分析は、データを解釈し、洞察を得るために統計学やデータ分析ツールを使用するプロセスを指します。 |
| 教育法人 | DataCamp DSA (DataCamp Certified Data Scientist Associate) | DataCamp | データサイエンスに関する知識とスキルを持つプロフェッショナル向けの資格です。データサイエンスは、データから意義深い情報を抽出し、ビジネスの意思決定に役立つ洞察を提供するためにデータ分析と機械学習を組み合わせた領域です。 |
| 協会 | CDMP (Certified Data Management Professionals) | DAMA International | CDMPは、データ管理に関する知識とスキルを持つプロフェッショナル向けの資格です。データ管理は、データの収集、整理、保存、保護、および活用に関連するさまざまなテクニカルスキルやベストプラクティスをカバーしています。この資格は、DAMA Internationalによって管理されており、データ管理分野での専門知識を証明するための国際的な標準として認識されています。CDMP資格を取得することで、データ管理における高度な能力を示すことができます。<br>※ 参考 [/space/knowledge/11632666/](/space/knowledge/11632666/) |
| ベンダー | AWS DEA (AWS Certified Data Engineer - Associate) | AWS | AWSのデータエンジニアリングに関する認定資格で、AWSのデータサービスを活用してデータパイプラインを構築および管理するスキルを評価します。 |
| ベンダー | AWS DAS (AWS Certified Data Analytics - Specialty) | AWS | AWSのデータ分析に関する認定資格で、AWSのデータ分析サービスを使用してデータを探索し、可視化し、洞察を得るスキルを評価します。 |
| ベンダー | AWS SAP (AWS Certified Solutions Architect - Professional) | AWS | AWSのソリューションアーキテクトに関する認定資格で、AWSクラウド上でアプリケーションを設計およびデプロイするスキルを評価します。 |
| ベンダー | AWS DBS (AWS Certified Database - Specialty) | AWS | AWSのデータベーススペシャリストに関する認定資格で、AWSデータベースサービスを管理および最適化するスキルを評価します。 |
| ベンダー | AWS MLS (AWS Certified Machine Learning - Specialty) | AWS | AWSの機械学習スペシャリストに関する認定資格で、AWS機械学習サービスを使用して機械学習モデルを構築およびトレーニングするスキルを評価します。 |
| ベンダー | GCP PCA (Google Cloud Professional Cloud Architect) | Google | Google Cloudのプロフェッショナルクラウドアーキテクトに関する認定資格で、GCPのクラウドアーキテクチャ設計スキルを評価します。 |
| ベンダー | GCP PDE (Google Cloud Professional Data Engineer) | Google | Google Cloudのプロフェッショナルデータエンジニアに関する認定資格で、GCPのデータエンジニアリングスキルを評価します。 |
| ベンダー | GCP PCA (Google Cloud Professional Cloud Architect) | Google | Google Cloudのプロフェッショナルクラウドアーキテクトに関する認定資格で、GCPのクラウドアーキテクチャ設計スキルを評価します。 |
| ベンダー | MCP DP-203 (Microsoft Certified: Azure Data Engineer Associate) | Microsoft | Microsoft Certified: Azure Data Engineer Associateに関する認定資格で、Microsoft Azureを使用してデータエンジニアリングソリューションを設計、実装、管理するスキルを評価します。 |
| ベンダー | Databricks DEA (Databricks Certified Data Engineer Associate) | Databricks | Databricks Certified Data Engineer Associateに関する認定資格で、Databricksプラットフォームを使用してデータエンジニアリングタスクを実行するスキルを評価します。 |
