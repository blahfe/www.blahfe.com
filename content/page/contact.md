# 副業依頼する前に

代表の猪瀬学（nabinno）にご連絡いただく前に、以下の事項をご確認ください。

# 1\. 勤務地

-   フルリモートのみ対応

# 2\. 連絡手段

-   Slackが主要な連絡手段

-   可能な限り迅速なレスポンスを心がける

-   打ち合わせにはZoomやGoogle Chatも利用可能

# 3\. 作業時間

-   月10-15時間の稼働を想定

-   作業内容に応じて調整可能

-   稼働時間帯は平日9:00-18:00の本業外

-   Slackでのコミュニケーションは制限なし（即応）

# 4\. 作業方針

-   AsIs-ToBeを基に情報整理

-   XY問題を避けるため問題点を明確に

-   証跡を積極的に残す

# 5\. 対応可能な内容と料金<br>
a. 情報セキュリティ管理などの設計支援

-   テキストベースの設計支援、状況により戦略支援も対応

-   他社事例の情報収集やベストプラクティスの確認から大まかな方針の壁打ちまで対応

-   料金はベストエフォートで回答から拘束時間に応じて変動 (0+ JPY / hour)

#<br>
b. 変更管理・構成管理の移行支援

-   CSP（Cloud Service Provider）の環境設定がメイン

-   要件ヒアリングから対応、ランブック納品も可能（別途お見積り）

-   料金はベストエフォートで回答から拘束時間に応じて変動

# 6\. 適格請求書発行事業者登録状況

-   適格請求書発行事業者になる予定はありません
